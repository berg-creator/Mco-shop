# Mco shop

Telegram-бот магазина одежды с мини-приложением: витрина с актуальным наличием,
категории, фильтры, корзина. Заказ приходит владельцу в личку заявкой с кнопками
«Подтвердить» и «Отказать».

## Что умеет

- **Витрина внутри Telegram.** Категории (куртки, штаны, кофты, обувь,
  аксессуары — список правится), фильтры по бренду, размеру, состоянию и цене,
  поиск, карточка с фото и описанием.
- **Наличие по размерам.** Проданный размер исчезает из витрины сам, вещь без
  единого размера в наличии уходит из каталога. Вручную ничего скрывать не надо.
- **Резерв, а не гонка.** Пока владелец не ответил на заявку, вещь считается
  занятой: двое не купят одну куртку. Отказ возвращает её в витрину.
- **Админка в боте.** Товар заводится с телефона: фото, название, бренд,
  категория, цена, размеры. Остатки правятся кнопкой.
- **Импорт из канала.** Архив постов магазина разбирается в карточки товаров.

Чего пока нет: онлайн-оплаты (заявка → переписка → оплата как договоритесь),
доставки через API служб, статистики продаж. Это следующие шаги, а не забытое.

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env               # вписать токен бота и свой Telegram id
.venv/bin/python -m src.db --init --demo   # база и десяток демо-товаров
```

Посмотреть витрину в браузере, без бота и токена:

```bash
.venv/bin/python -m src.app --web-only     # http://127.0.0.1:8080/app/
```

## Как запустить по-настоящему

Telegram пускает в мини-приложение только по HTTPS, поэтому локальному
магазину нужен туннель — он выдаёт временный адрес с сертификатом.

```bash
brew install cloudflared
cloudflared tunnel --url http://127.0.0.1:8080
```

Команда напечатает адрес вида `https://что-то.trycloudflare.com`. Его нужно
вписать в `.env` **с завершающим `/app/`**:

```
WEBAPP_URL=https://что-то.trycloudflare.com/app/
```

Дальше:

```bash
.venv/bin/python -m src.app
```

Магазин работает, пока живы туннель и этот процесс. Адрес туннеля меняется
при каждом запуске — поэтому это режим показать и проверить, а не продавать.

Что нужно завести один раз:

1. **Бот** — [@BotFather](https://t.me/BotFather) → `/newbot` → токен
   в `TELEGRAM_BOT_TOKEN`.
2. **Свой id** — [@userinfobot](https://t.me/userinfobot) → число в `ADMIN_IDS`.
   Через запятую можно указать двоих: владельца и помощника.

## Каталог

**С телефона.** В боте: `/add` — мастер из семи шагов, `/items` — список
товаров с кнопками «Остаток», «Скрыть», «Удалить», `/orders` — последние заявки.

**Из канала.** Telegram Desktop → Настройки → Экспорт данных → канал магазина,
формат JSON, с фотографиями. Дальше:

```bash
.venv/bin/python -m src.importer ~/export/result.json --out draft.json
```

Разбор эвристический: цена, размеры, бренд и категория угадываются из текста
поста, посты без цены пропускаются, помеченные «продано» не заливаются.
Поэтому шага два: сначала черновик `draft.json`, который нужно просмотреть
глазами и поправить, потом заливка:

```bash
.venv/bin/python -m src.importer --apply draft.json
```

## Заявки

Покупатель оформляет заказ в витрине → заявка падает владельцу в личку:
кто, телефон, доставка, позиции, сумма. Кнопка «Подтвердить» списывает остаток
и пишет покупателю, что вещи отложены. «Отказать» снимает резерв и возвращает
вещь в витрину. Кнопка «Написать покупателю» открывает с ним диалог.

## Переезд на VPS

Локальный запуск — для проверки. Чтобы магазин работал круглосуточно, нужен
хостинг с постоянным адресом (Timeweb, Amvera, Beget — от 200 ₽ в месяц):

1. `git clone`, `python3 -m venv .venv`, `pip install -r requirements.txt`.
2. `.env` с постоянным `WEBAPP_URL` (домен с сертификатом, например через
   nginx + Let's Encrypt или встроенный HTTPS хостинга).
3. Юнит systemd с `ExecStart=/путь/.venv/bin/python -m src.app` и
   `Restart=always`.
4. Резервная копия `data/` — там весь каталог, фото и история заказов.

Код при этом не меняется: тот же процесс, тот же long polling.

## Проверка

```bash
.venv/bin/python -m src.app --check          # настройки и база
.venv/bin/python -m src.db --check           # что лежит в каталоге
.venv/bin/python -m unittest discover tests  # остатки, подпись, разбор постов
```
